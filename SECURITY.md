# Security

## reporting a problem

If you find a security issue in any Differend Labs repository or on [differend.ai](https://differend.ai), please report it privately. Do not open a public issue.

Two ways to report:

1. On GitHub, go to the repo's **Security** tab and choose **Report a vulnerability**.
2. Or email [hello@differend.ai](mailto:hello@differend.ai) with "Security" in the subject.

Please include what you found, where, and the steps to see it.

## what happens next

- You get a reply within 7 days.
- The issue is fixed as quickly as possible, and you are kept updated.
- Once it is fixed, you are credited in the fix notes if you want to be.

## what counts

Code, data, and website issues are all welcome. This includes study data that exposes private information by mistake.

# Getting help

- **A question about a study:** open an issue in that study's repo.
- **A question about AI in general:** start with [the learn page](https://differend.ai/learn) or [From counting to ChatGPT](https://differend.ai/journey). If it is still unclear, that is a gap worth reporting.
- **Anything else:** email [hello@differend.ai](mailto:hello@differend.ai).

Differend Labs is a small lab, so replies can take a few days.

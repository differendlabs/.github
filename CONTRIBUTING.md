# Contributing to Differend Labs

Thanks for being here. Differend Labs is small, so every report and question gets read.

## ways to help

- **Try to reproduce a study.** Each study repo has its plan, code, and results. If you run it and get something different, that is useful. Open an issue with the "Reproduction report" form.
- **Report a problem.** A bug in the code, a wrong number in a write-up, or a broken link. Use the "Something is wrong" form.
- **Tell us something is unclear.** Every write-up should make sense to someone outside the tech industry. If a sentence lost you, it needs fixing. Use the "This is hard to understand" form.
- **Ask a question.** See [SUPPORT.md](SUPPORT.md).

## before you open a pull request

1. Open an issue first for anything larger than a typo, so the change can be discussed.
2. Keep each pull request to one change.
3. Study plans are fixed once a study starts. Changes to a running study's plan are not accepted. A deviation note can be added instead, and it is published with the results.
4. If you change code, run the repo's tests (usually `make test`) and say what you ran.
5. Write plainly. Use short sentences and explain any technical word the first time it appears.

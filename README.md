# .github

Shared settings for every [Differend Labs](https://differend.ai) repository.

## what's here

| file | what it does |
|---|---|
| `profile/README.md` | the public page at [github.com/differendlabs](https://github.com/differendlabs) |
| `CONTRIBUTING.md` | how to help, report a problem, or try to reproduce a study |
| `CODE_OF_CONDUCT.md` | how people treat each other here |
| `SECURITY.md` | how to report a security issue privately |
| `SUPPORT.md` | where to ask questions |
| `.github/ISSUE_TEMPLATE/` | issue forms used by any repo that has none of its own |
| `.github/pull_request_template.md` | the default pull request checklist |

A repo that has its own copy of one of these files uses its own copy instead.
